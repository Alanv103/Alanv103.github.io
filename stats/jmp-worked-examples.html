One mean — Life Expectancy: μ₀ = 78.54, x̄ = 79.52, s = 16.41, n = 200

Standard error of x̄ (s given, so it's a t-test)SE = s/√n = 16.41/√200 = 16.41/14.1421 ≈ 1.1604

Test statistict = (x̄ − μ₀)/SE = (79.52 − 78.54)/1.1604 = 0.98/1.1604 ≈ 0.8446

Degrees of freedomdf = n − 1 = 200 − 1 = 199

p-value (two-tailed, H₁: μ ≠ 78.54)p = 2 × P(T₁₉₉ > 0.8446) ≈ 0.3993 ← JMP's Prob>|t|

95% confidence interval for μx̄ ± t(.025, 199)·SE = 79.52 ± 1.9720(1.1604) = 79.52 ± 2.2882 → (77.23, 81.81)

If σ is given instead, it's a z-test — Time Perception: μ₀ = 45, σ = 9.5, n = 20, x̄ = 59.30SE = σ/√n = 9.5/√20 = 9.5/4.4721 ≈ 2.1243 z = (59.30 − 45)/2.1243 = 14.30/2.1243 ≈ 6.73

If only s² is given — Home Prices: x̄ = 141,400, μ₀ = 155,000, s² = 7,317,400,000, n = 69s = √7,317,400,000 ≈ 85,542 ← square-root the variance first SE = 85,542/√69 = 85,542/8.3066 ≈ 10,298 t = (141,400 − 155,000)/10,298 = −13,600/10,298 ≈ −1.32

Power and β — Soap: μ₀ = 33, σ = 12.4, n = 35, α = .05, "less than" test

Step 1 — standard errorSE = σ/√n = 12.4/√35 = 12.4/5.9161 ≈ 2.096

Step 2 — the rejection cutoff (z is negative for a "less than" test)x̄c = μ₀ + (z)(SE) = 33 + (−1.645)(2.096) = 33 − 3.448 ≈ 29.55 ← reject H₀ if x̄ < 29.55

Step 3 — re-measure that cutoff from the true mean (true mean = 29)z = (x̄c − μtrue)/SE = (29.55 − 29)/2.096 = 0.55/2.096 ≈ 0.263

Step 4 — power, then βPower = P(Z < 0.263) ≈ 0.6039 → 60.39% β = 1 − Power = 1 − 0.6039 ≈ 0.3961Matches your homework key: power 60.39%, Type II error 0.3961.

Two-tailed cutoffs — Score: μ₀ = 75, σ = 8, n = 16, α = .05SE = 8/√16 = 8/4 = 2 x̄c = μ₀ ± zα/₂(SE) = 75 ± 1.96(2) = 75 ± 3.92 → reject if x̄ < 71.08 or x̄ > 78.92

β for a two-tailed test (true mean = 76)zlow = (71.08 − 76)/2 = −2.46 zhigh = (78.92 − 76)/2 = 1.46 β = P(−2.46 < Z < 1.46) = 0.9279 − 0.0069 ≈ 0.9209 Power = 1 − 0.9209 ≈ 0.0791Power is tiny because 76 is only half a standard error from 75 — a small effect is hard to detect.

Two proportions, separate groups — Statistician: 222 of 515 with help, 55 of 190 without

Sample proportions (divide by that group's own row total)p̂₁ = 222/515 ≈ 0.4311 p̂₂ = 55/190 ≈ 0.2895

Point estimate of the differencep̂₁ − p̂₂ = 0.4311 − 0.2895 = 0.1416

Pooled proportion (for the test only, never the interval)p̂ = (x₁ + x₂)/(n₁ + n₂) = (222 + 55)/(515 + 190) = 277/705 ≈ 0.3929

Test statisticz = (p̂₁ − p̂₂) / √[p̂(1−p̂)(1/n₁ + 1/n₂)] = 0.1416 / √[0.3929(0.6071)(1/515 + 1/190)] = 0.1416/0.04146 ≈ 3.42

p-value (one-tailed, "does help improve publication?")p = P(Z > 3.42) ≈ 0.0003 → reject H₀ at α = .01

95% interval for p₁ − p₂ (not pooled)SE = √[p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂] ≈ 0.03948 CI = 0.1416 ± 1.96(0.03948) = 0.1416 ± 0.0774 → (0.0642, 0.2190) all above 0, so help really does raise the rate

Large-sample check (all four cell counts ≥ 5)222, 293, 55, 135 — all ≥ 5 ✓

Two proportions, same people twice — Smoking: a = 20, b = 5, c = 16, d = 9, n = 50

Throw out the ties, keep the switchersties = a + d = 20 + 9 = 29 ← dropped n′ = b + c = 5 + 16 = 21 T = 16 ← the 16 who went smoker → non-smoker

p-value (exact binomial, like flipping 21 coins)T ~ Binomial(21, 0.5) p = P(T ≥ 16) = 1 − BinomialDistribution(.5, 21, 15) ≈ 0.0133 → under .05, so the video worked

95% interval for p_b − p_c(b − c)/n = (5 − 16)/50 = −0.22 √[((a+d)(b+c) + 4bc)/n³] = √[((29)(21) + 4(5)(16))/125,000] = √[929/125,000] ≈ 0.0862 CI = −0.22 ± 1.96(0.0862) = −0.22 ± 0.169 → (−0.389, −0.051) all below 0, so far more quit than started

Simple regression — demo set: x = 2, 4, 6, 8, 10  ·  y = 3, 7, 8, 12, 14  (n = 5)

The two averagesx̄ = (2+4+6+8+10)/5 = 30/5 = 6 ȳ = (3+7+8+12+14)/5 = 44/5 = 8.8

Sxx — spread of the x'sSxx = Σ(x − x̄)² = (−4)² + (−2)² + 0² + 2² + 4² = 16 + 4 + 0 + 4 + 16 = 40

Syy — spread of the y'sSyy = Σ(y − ȳ)² = (−5.8)² + (−1.8)² + (−0.8)² + (3.2)² + (5.2)² = 33.64 + 3.24 + 0.64 + 10.24 + 27.04 = 74.8

Sxy — how x and y move togetherSxy = Σ(x − x̄)(y − ȳ) = (−4)(−5.8) + (−2)(−1.8) + (0)(−0.8) + (2)(3.2) + (4)(5.2) = 23.2 + 3.6 + 0 + 6.4 + 20.8 = 54

Slopeb₁ = Sxy/Sxx = 54/40 = 1.35

Intercept (needs b₁ first)b₀ = ȳ − b₁x̄ = 8.8 − 1.35(6) = 8.8 − 8.1 = 0.7

The line, then a prediction at x = 7ŷ = 0.7 + 1.35x ŷ = 0.7 + 1.35(7) = 0.7 + 9.45 = 10.15

Residual for the point (8, 12)e = y − ŷ = 12 − [0.7 + 1.35(8)] = 12 − 11.5 = 0.5

Correlationr = Sxy/√(Sxx·Syy) = 54/√(40 × 74.8) = 54/√2992 = 54/54.699 ≈ 0.9872 strong and positive

R²R² = r² = (0.9872)² ≈ 0.9746 → 97.46% of the variation in y explained

Test statistic for the slopeSSE = Syy − b₁(Sxy) = 74.8 − 1.35(54) = 74.8 − 72.9 = 1.9 s = √[SSE/(n−2)] = √(1.9/3) = √0.6333 ≈ 0.7958 SE(b₁) = s/√Sxx = 0.7958/6.3246 ≈ 0.1258 t = b₁/SE(b₁) = 1.35/0.1258 ≈ 10.73 df = n − 2 = 3

95% interval for the slopeb₁ ± t(.025, 3)·SE(b₁) = 1.35 ± 3.1824(0.1258) = 1.35 ± 0.4004 → (0.950, 1.750) does not contain 0, so x really does help predict y

Several predictors — Supervisor Performance, straight off the JMP report: R² = 0.713223, n = 30, k = 6 predictors

Adjusted R² (the one that compares models of different sizes)R²adj = 1 − (1 − R²)(n − 1)/(n − k − 1) = 1 − (1 − 0.713223)(29)/(23) = 1 − (0.286777)(1.2609) = 1 − 0.3616 ≈ 0.6384JMP prints RSquare Adj = 0.638412 — matches, so the formula is doing what JMP does.

Overall F (from the Analysis of Variance table)F = MS Model / MS Error = 491.193/51.522 ≈ 9.53 df = k = 6 and n − k − 1 = 23JMP prints F Ratio = 9.533. H₀ is that every slope is 0.

Degrees of freedom for one coefficientdf = n − k − 1 = 30 − 6 − 1 = 23

Test statistic for any one coefficientt = bₖ/SE(bₖ) both columns sit in Parameter Estimates

Curved (quadratic) model — the change in y is different every time

Change in y from x₁ to x₂ (example coefficients b₁ = 5, b₂ = −0.5)change = b₁(x₂ − x₁) + b₂(x₂² − x₁²) 0 → 1: 5(1 − 0) + (−0.5)(1 − 0) = 5 − 0.5 = 4.5 2 → 3: 5(3 − 2) + (−0.5)(9 − 4) = 5 − 2.5 = 2.5Same one-unit step, different answer — that is exactly why the question asks for both.

Shortcut for a one-unit step0 → 1 is always b₁ + b₂ 2 → 3 is always b₁ + 5b₂ (because 3² − 2² = 5)
