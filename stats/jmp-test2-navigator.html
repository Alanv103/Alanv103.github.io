The decision rule — same for all four tests

Compare p to α. That is the whole decision. p < αREJECT H₀ → "there IS sufficient evidence that …" p > αFAIL TO REJECT H₀ → "there is NOT sufficient evidence that …" Never write "accept H₀" and never write "prove". You only ever reject or fail to reject.

Comparing the decimals — line them up exampleα = 0.0100  ·  p < 0.0001  →  p is smaller → reject More zeros after the point = smaller number. 0.0001 is 1 in 10,000; 0.01 is 1 in 100. A tiny p is strong evidence against H₀. JMP prints 0.0000 or <.0001 because it ran out of decimals — you write p < 0.0001, never p = 0. Same p can flip the answer: p = 0.032 rejects at α=0.05 but fails to reject at α=0.01. Find α in the question first.

Write it p first saySince p p-value is less than α = .05 or .01, we reject H₀. There is sufficient evidence that H₁ in plain words. saySince p p-value is greater than α = .05 or .01, we fail to reject H₀. There is not sufficient evidence that H₁ in plain words. One-sided? Name the direction ("higher for the new method"), not just "different".

T1 · Two independent means — two-sample t

a Raw data, or just summary numbers? raw rowsAnalyze › Fit Y by X › Y = response, X = group › OK only n, x̄, sHelp › Sample Index › Tool › Calculators › TestTwoSampleMeans › t-test › Assume Equal Variances › pick H₁ Fit Y by X cannot run on summary statistics. It needs actual rows. The calculator gives you NO Brown-Forsythe and NO quantile plot — argue conditions from the problem text and the SD ratio by hand.

b Turn on everything you need, once ▼Means/Anova/Pooled t  ·  t Test  ·  Unequal Variances  ·  Normal Quantile Plot That one click-set answers conditions, test statistic, p-value and CI.

c Variables and parameters sayThe explanatory variable is what splits the groups, which is categorical with 2 levels. The response is what you measured + units, which is quantitative. sayμ₁ = the true mean what + units for all group 1, and μ₂ = the true mean for all group 2. sayThe point estimate is x̄₁ − x̄₂ = mean 1 − mean 2 = answer. Parameters are about the whole population, never the numbers you were handed.

d Hypotheses — watch the wording two-sided"a difference", "differ", "changed" → H₁: μ₁ ≠ μ₂ one-sided"higher", "greater", "more than", "improved" → H₁: μ₁ > μ₂ sayH₀: μ₁ = μ₂    H₁: μ₁ < > or ≠ μ₂

e Conditions — all three, in this order sayIndependence: subjects were randomly assigned (or randomly sampled) and each appears in only one group, so the two samples are independent. sayNormality: n = group size per group. If n ≥ 30: the Central Limit Theorem applies, so no plot is needed. If n < 30: the Normal Quantile Plot shows the points following their lines with no curve or outliers. sayEqual variances: the SDs are s1 and s2, a ratio of bigger÷smaller which is under 2, and Brown-Forsythe gives p = p-value > 0.05, so pooling is appropriate. SD ratio under 2 = variance ratio under 4. Fails? Don't stop — quote the t Test (Welch) box instead of Pooled t. Conditions 1 and 2 are required either way.

f Test statistic and p-value equal varPooled t Test box → t Ratio, DF = n₁+n₂−2, Prob > |t| unequalt Test box ("Assuming unequal variances") → decimal DF sayIf H₀ were true, there would be about a p as a % chance of getting a difference in sample means this far from 0 just by random chance. One-sided? Use Prob > t or Prob < t, never Prob > |t|. Read the header (e.g. B−A) to see the subtraction order. Safety check: the right one-sided p is below 0.5 when the data lean the way H₁ says. Got 0.9997? Take the other row.

g Conclusion Use The decision rule at the top of this page: compare p to α, then write the sentence in context, naming the direction.

h Confidence interval readUpper CL Dif and Lower CL Dif in the same t-test box sayWe are 95% confident the true difference in mean what + units is between Lower CL and Upper CL. CI excludes 0 ↔ you rejected H₀. They always agree. If asked "will it contain 0?" before computing → answer from the p-value.

T2 · Matched pairs — same subject measured twice

a Run it pathAnalyze › Specialized Modeling › Matched Pairs thenput BOTH columns into Y, Paired Response › OK One box, two columns. Do not stack this data.

b Equivalent route, if asked the long way make colCols › New Column › Column Properties › Formula → after − before thenAnalyze › Distribution › ▼ › Test Mean › 0 Identical t and p. The difference column is also how you check normality.

c Hypotheses sayLet μd be the true mean difference (after minus before) for all subjects. sayH₀: μd = 0    H₁: μd < > or ≠ 0

d Conditions — only two, and one is different sayIndependence: the pairs were randomly sampled and one pair does not affect another. The two values within a pair are dependent by design, which is the point. sayNormality: the differences are approximately normal — the quantile plot of the difference column shows no curve or outliers. Normality applies to the differences, not to either original column. There is no equal-variance condition here.

e Read it and conclude readMean Difference · t-Ratio · DF = n−1 · Prob > |t| · Upper95% / Lower95% 5 pairs → df = 4, not 8. JMP prints the subtraction order in the label (e.g. 2022-2020); the second column minus the first flips only the sign, never the p-value. saySince p = p-value < α = .05, we reject H₀. There is sufficient evidence of a difference in mean what + units between time 1 and time 2.

f Confidence interval for the difference readUpper95% and Lower95% in the same box sayWe are 95% confident the true mean difference in what + units is between Lower95% and Upper95%. It excludes 0, agreeing with rejecting H₀.

g Why pairing is worth it Pairing strips out subject-to-subject variation, so t gets bigger. Run wrongly as two independent samples the same data gives a much weaker result. That's the answer if asked why you paired.

T3 · One-way ANOVA — one factor, 3+ groups

a Run it pathAnalyze › Fit Y by X › Y = response, X = factor › OK ▼Means/Anova  ·  Unequal Variances  ·  Normal Quantile Plot X must be Nominal (red bars). If it's Continuous you get a regression, not an ANOVA.

b Hypotheses sayH₀: μ₁ = μ₂ = μ₃ = … (all group means are equal) sayH₁: at least one mean differs from the others Never write "all means are different". That is wrong and gets marked.

c DF check before you read anything checkFactor DF = k−1  ·  Error DF = N−k  ·  C. Total = N−1 5 groups of 25: 4, 120, 124. Wrong DF → wrong column selected or wrong modeling type.

d Conditions sayIndependence: subjects were randomly assigned to the groups. sayNormality: n = group size per group and the quantile plots show points near their lines. sayEqual variances: largest SD / smallest SD = ratio, under 2, and Brown-Forsythe p = p-value > 0.05. With 3+ groups the rule is largest over smallest, not pairwise.

e The F test and your conclusion readAnalysis of Variance table → F Ratio and Prob > F saySince p = Prob > F < α = .05, we reject H₀. There is sufficient evidence that at least one mean what + units differs. saySince p = Prob > F > α = .05, we fail to reject H₀. There is not sufficient evidence that the means differ, so we do not make multiple comparisons.

f Multiple comparisons — only if F was significant ▼Compare Means › All Pairs, Tukey HSD "If appropriate" means exactly this: F not significant → stop. 10 t-tests at 5% each = ~40% false-positive risk; Tukey holds the overall rate at 5%.

g Reading connecting letters ruleshare a letter → NOT different  ·  no letter in common → different sayTukey HSD comparisons at an overall 0.05 level showed that groups sharing a letter did not differ, while group was significantly higher/lower than group.

T4 · Two-way ANOVA — two factors, Fit Model

a Name the factors, their levels, and the response sayThe two factors are factor A, categorical with # levels (list them), and factor B, categorical with # levels (list them). sayThe response variable is what + units, which is quantitative. sayThere are a×b treatment combinations with n per cell units each, so the design is balanced and the interaction can be tested.

b Run it — the Cross step is everything 1Analyze › Fit Model › Y, Response = the response 2Add both factors 3select BOTH inside Construct Model Effects › click Cross 4Run Three lines must show before Run: A, B, A*B. Only two → you skipped Cross and the interaction is missing. (Macros › Full Factorial does all of it in one click.)

c DF check — your safety net formulaModel DF = (a−1) + (b−1) + (a−1)(b−1) 3×3, n=4Model 8 · Error 27 · C. Total 35 3×2, n=5Model 5 · Error 24 · C. Total 29 Model DF too small → no interaction in the model. Go back and Cross. This check catches the wrong-file mistake too.

d Three sets of hypotheses — write all three sayInteraction — H₀: there is no interaction between factor A and factor B. H₁: there is an interaction. sayFactor A — H₀: μ₁ = μ₂ = μ₃. H₁: at least one differs. sayFactor B — H₀: μ₁ = μ₂. H₁: they differ.

e Read the INTERACTION row first. Always. readEffect Tests table → the A*B row → Prob > F

This single decision controls the whole rest of the problem.

Five traps

Check these before you hand it in 1 "higher / greater / more" = one-sided → Prob > t or Prob < t; "a difference / differ" = two-sided → Prob > |t|. The right one-sided p is under 0.5. 2 Forgetting Cross → three effects in the box and Model DF matches the formula, or the interaction never got tested. 3 Reading main effects over a significant interaction → interaction row first, every time. 4 Wrong layout: Fit Y by X = stacked, Matched Pairs = side by side. X must be Nominal. 5 H₁ for ANOVA is at least one mean differs, never "all means are different".
