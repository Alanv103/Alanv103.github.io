Q2 · Power & Type I / II error — mostly by formula, not by menu

The whole idea in 3 steps — works for any power question1SE = σ/√n2cut-off on the x̄ scale, centred at μ₀: right μ₀+zαSE · left μ₀−zαSE · two-sided μ₀±zα/₂SE (two cut-offs)3re-centre on the true μ: z = (cut-off − μtrue)/SE, then read the reject-side area = Power, and β = 1 − PowerThe cut-off never moves — only the centre of the curve moves.

aDescribe the sampling distribution of x̄ under H₀jmpnone — it is just μ₀ and σ/√nsayShape: approximately normal, because .  Mean: μ₀ = .  Standard deviation: σ/√n = /√ = .Reason blank: "σ is known and the population is stated normal" or "n ≥ 30, so the CLT applies".

bFor what values of x̄ is H₀ rejected?saycut-off = μ₀ + (z)(SE) = + ()() = → "reject H₀ for any sample mean [above / below] ."z carries the sign of the tail: −1.645 for a "less than" test, +1.645 for "greater than", ±1.96 two-sided at α = .05.

cPower, and the Type II rate βsayz = (cut-off − μtrue)/SE = ( − )/ = ; Power = and β = 1 − Power = Two-sided: work out both tails and add them (one is usually tiny, but show it).

Worked example — Soapμ₀ = 33, σ = 12.4, n = 35, α = .05 "less than", true mean 29 SE = σ/√n = 12.4/√35 = 12.4/5.9161 ≈ 2.096 cut-off = 33 + (−1.645)(2.096) = 33 − 3.448 ≈ 29.55 z = (29.55 − 29)/2.096 = 0.55/2.096 ≈ 0.263 Power = P(Z < 0.263) ≈ .6039 → 60.39% β = 1 − .6039 ≈ .3961

Two-tailed power — do both tailsScore: μ₀ = 75, σ = 8, n = 16, α = .05, true mean 76 SE = 8/√16 = 8/4 = 2 cuts = 75 ± 1.96(2) = 75 ± 3.92 → 71.08 and 78.92 zlow = (71.08 − 76)/2 = −2.46 zhigh = (78.92 − 76)/2 = 1.46 β = .9279 − .0069 ≈ .9209 Power = 1 − .9209 ≈ .0791Power is tiny because 76 is only half a standard error from 75 — a small gap is hard to detect.

dType I and Type II in contextsayType I: "concluding when in reality ."  Type II: "concluding there is not enough evidence that when in reality it is true."

eIf an error was committed, which type?say"We [rejected / failed to reject] H₀, so only a Type [I / II] error is possible: ."Set by your decision, not by the data.

Power from JMPjmpDOE › Design Diagnostics › Sample Size and Power › One Sample Mean → fill Alpha, Std Dev, Difference to Detect, Sample Size, leave Power empty › ContinueTwo-sided by default, so on a one-tailed question trust the 3 steps above. Leaving Sample Size empty instead answers "how big a sample do I need".

What moves powerPower rises with n↑, α↑, a bigger gap |μtrue − μ₀|, and σ↓. Raising n is the only one with no downside. Reduce Type I → lower α; reduce Type II → raise power.

Sketch itTwo bell curves on one axis with a single vertical line at the cut-off through both. Top curve centred at μ₀, tail past the cut-off shaded = α. Bottom curve centred at the true μ, the "don't reject" side shaded = β, the rest = power.
