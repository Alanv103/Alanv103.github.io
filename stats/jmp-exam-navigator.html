JMP Exam NotesOne mean · Power · Two proportions

› = then click  ·  ▼ = red triangle on that report's title bar  ·  → = where the answer appears  ·  reject H₀ when p ≤ α

Setting up

Open the data. File › Open › the .jmp file. A quantitative column must read Continuous — right-click the column header › Column Info › Modeling Type.

Categorical or quantitative? A number you could average is quantitative (weight, diameter, price, pounds). A label putting each unit in a group is categorical (accepted/rejected, smoker/non-smoker).

Define the parameter. Write "μ = the true mean [variable, with units] for all [population]." Name the mean, the units, and the population.

Hypotheses. H₀: μ = μ₀ always. "less / decreased" → H₁: μ < μ₀ · "greater / increased" → μ > μ₀ · "different / changed" → μ ≠ μ₀. Never put x̄ in a hypothesis.

Shape, x̄, s, n. Analyze › Distribution › Y, Columns = variable › OK → histogram for shape; Summary Statistics for Mean, Std Dev, N, Std Err Mean.

Testing one mean

t test (σ not given). Analyze › Distribution › Y = variable › OK › ▼variable › Test Mean › type μ₀ › leave the SD box empty › OK → Test Mean panel, t Test row.

z test (σ given). Same path, but also fill "Enter True Standard Deviation to do z-test rather than t test" → the panel now shows a z Test row.

Pick the right p-value. H₁ is ≠ → Prob>|t| · H₁ is > → Prob>t · H₁ is < → Prob<t. Ignore the Signed-Rank row.

No data, only summary stats. Distribution needs raw data, so compute by hand: t = (x̄ − μ₀) / (s/√n), df = n − 1. If they give s², take the square root first.

Interpret the test statistic: "The sample mean is t standard errors above / below μ₀, the value H₀ claims."

Interpret the p-value: "If μ really were μ₀, there is a __% chance of getting a sample mean at least this far from μ₀ by random sampling alone."

Conclusion, p ≤ α: "Since p < α, we reject H₀. There is sufficient evidence to conclude [H₁ in words]."

Conclusion, p > α: "Since p > α, we fail to reject H₀. There is insufficient evidence to conclude [H₁ in words]." Never write "accept H₀."

Conditions and intervals

Conditions for the t test. Independence: a random sample, less than 10% of the population, one measurement per unit. Normality: the problem states bell-shaped, or n ≥ 30 so the CLT applies, or a symmetric histogram with no outliers.

Check normality in JMP. ▼variable › Continuous Fit › Normal › ▼Fitted Normal › Goodness of Fit → Shapiro-Wilk Prob<W; above α means normality is reasonable. Add ▼variable › Normal Quantile Plot and say the points follow the line inside the bands.

Confidence interval for μ. Summary Statistics already lists Upper / Lower 95% Mean. Other levels: ▼variable › Confidence Interval › 0.90 / 0.95 / 0.99. By hand x̄ ± t(α/2, n−1)·s/√n.

Interpret it: "We are 95% confident the true mean [variable] for all [population] is between ___ and ___."

Probability about an average. z = (x̄ − μ)/(σ/√n), or Cols › New Column › Formula › Probability › Normal Distribution(a, μ, σ/√n) which gives P(x̄ < a); subtract from 1 for "more than".

Sampling distribution & power

Describe the sampling distribution of x̄ when H₀ is true. Give all three. Shape: bell-shaped / normal — because the population is normal, or by the CLT when n ≥ 30. Mean: μ₀. Standard deviation: σ/√n (this is the standard error).

What values of x̄ lead to rejection? critical value = μ₀ + (z)(SE), with SE = σ/√n and z signed by the tail: left −1.645, right +1.645 at α = .05; two-tailed μ₀ ± 1.96·SE. Reject when x̄ is past it.

β = P(Type II error). Re-standardize that same critical value using the true mean: z = (x̄c − μtrue)/(σ/√n), then β = P(x̄ lands in the fail-to-reject region).

Power = 1 − β. "Probability of detecting this difference", "probability of rejecting H₀ when the true mean is ___" and "probability of correctly concluding" all mean power. "Probability of failing to reject" and "incorrectly failing to reject" mean β.

Worked example. μ₀ = 50, σ = 21, n = 36, α = .05, left-tailed. SE = 21/6 = 3.5; x̄c = 50 − 1.645(3.5) = 44.24. If μtrue = 43: z = (44.24 − 43)/3.5 = .354, β = .3613, power = .6387.

Power from JMP. DOE › Design Diagnostics › Sample Size and Power › One Sample Mean, fill Alpha, Std Dev, Difference to Detect and Sample Size, leave Power blank › Continue. Leaving Sample Size blank instead answers "how big a sample do I need". It is two-sided by default, so trust the hand computation on one-tailed problems.

Sketch. Two normal curves sharing one axis: top centered at μ₀ with the tail past x̄c shaded = α; bottom centered at μtrue with the fail-to-reject side shaded = β and the other side = power. One vertical line at x̄c through both.

Which error is possible? If you rejected H₀, only a Type I error. If you failed to reject, only a Type II. Power rises when n↑, α↑, |μtrue − μ₀|↑, or σ↓.

Type I in context: "We conclude [H₁ in words] when in reality [H₀ in words]." Probability α.

Type II in context: "We conclude there is not enough evidence for [H₁] when [H₁] is actually true." Probability β.

Two proportions — independent groups

Type in a 2×2 count table. File › New › Data Table with three columns — Group (Nominal), Outcome (Nominal), Count (Continuous) — and one row per cell, e.g. (Help, Accepted, 222).

Analyze it. Analyze › Fit Y by X › Y = Outcome › X = Group › Freq = Count › OK → Contingency Table and Tests. Forgetting the Freq box makes JMP analyze only 4 observations.

Point estimate. ▼Contingency Table › Row %. Each p̂ is the cell divided by its own row total, never the grand total; the estimate is p̂₁ − p̂₂. Example: 222/515 − 55/190 = .4311 − .2895 = .1416.

Hypotheses. H₀: p₁ − p₂ = 0. If the rates are the same in both groups the difference is zero. "improves" → > 0 · "reduces" → < 0 · "different" → ≠ 0.

Assumptions. Independently chosen random samples or random assignment; independence within each group (one response per person); and n₁p̂₁, n₁(1−p̂₁), n₂p̂₂, n₂(1−p̂₂) all ≥ 5 — which is just all four cell counts being at least 5.

Test and interval. ▼Contingency Analysis › Two Sample Test for Proportions → the difference, its standard error, Prob>|z| / Prob>z / Prob<z, and the confidence interval. Pearson ChiSquare in the Tests panel is the same two-sided test (χ² = z²).

By hand. pooled p̂ = (x₁+x₂)/(n₁+n₂); z = (p̂₁−p̂₂) / √[p̂(1−p̂)(1/n₁+1/n₂)]. The interval is not pooled: (p̂₁−p̂₂) ± zα/₂√[p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂].

Interpret the p-value: "If the acceptance rate really were the same in both groups, there would be a __% chance of seeing a difference in sample proportions at least this large."

Two proportions — paired

Spot it. The same people measured twice, or matched pairs (before/after the video, younger/older siblings). Never use the two-proportion z test here — it throws away the pairing.

Label the table. a and d are the ties (no change); b and c are the discordant pairs that changed in each direction. Smoking: a = 20, b = 5, c = 16, d = 9, n = 50.

Ties, n′, T. ties = a + d, n′ = b + c, and T is the count in the direction H₁ predicts. Smoking: ties = 29, n′ = 21, T = 16. H₀: p_b = p_c, i.e. changes are equally likely both ways.

p-value, exact binomial. Under H₀, T ~ Binomial(n′, 0.5). Cols › New Column › Formula › Discrete Probability › Binomial Distribution(.5, n′, k) gives P(T ≤ k). Smoking: 1 − BinDist(.5, 21, 15) = .0133 < .05, so reject — the video was effective.

Or from JMP. Analyze › Fit Y by X › Y = After, X = Before, Freq = Count › OK › ▼ › Agreement Statistic → the test of symmetry is McNemar's test, but two-sided only.

Interval. (b−c)/n ± zα/₂√[((a+d)(b+c) + 4bc) / n³]. Smoking gives (−.389, −.051), entirely below 0. Puzzle gives (−.196, .077), which contains 0 — no significant difference.

Critical values & formula functions

z critical values: one-tailed α = .10 → 1.282, .05 → 1.645, .025 → 1.960, .01 → 2.326, .005 → 2.576. Two-tailed 90% → 1.645, 95% → 1.960, 98% → 2.326, 99% → 2.576.

JMP formula functions: t Quantile(1−α/2, df), Normal Quantile(1−α), t Distribution(t, df) (left tail), 2*(1 − t Distribution(|t|, df)) for a two-sided p-value.

JMP Exam NotesCorrelation · Simple, multiple & polynomial regression

Correlation & the fitted line

Which variable is which. "Predict A using B" means y = A (response) and x = B (explanatory). In JMP the response goes in Y, Response and the explanatory in X, Factor.

Scatterplot. Analyze › Fit Y by X › Y, Response = response › X, Factor = factor › OK. Comment on four things: direction, form, strength, and any unusual points. If the cloud bends, say a quadratic should be considered.

Add the line. ▼Bivariate Fit › Fit Line → the equation is printed as text just above Summary of Fit.

Correlation r. Analyze › Multivariate Methods › Multivariate › both variables in Y, Columns › OK → Correlations, the off-diagonal value. Or r = ±√RSquare taking the sign of the slope. |r| ≥ .8 strong, .5–.8 moderate, below .5 weak.

Equation of the least squares line. Analyze › Fit Model › Y = response › select x › Add › Run → Parameter Estimates, Estimate column: the Intercept row is b₀, the x row is b₁. Write it with real names, not y and x.

Predict. Substitute into ŷ = b₀ + b₁x. Watch units — if x is in thousands, 34,000 employees means x = 34. Don't extrapolate far outside the data.

Interpret the slope: "For each additional one [x-unit], the predicted (average) [y] increases / decreases by b₁ [y-units]." Say predicted or average, and never claim x causes y.

Interpret the intercept: "When x = 0, the predicted [y] is b₀." Add a caveat if x = 0 is outside the data or impossible.

Checking the conditions

Save what you need. ▼Response y › Save Columns › Residuals, then repeat for Predicted Values and Studentized Residuals → new columns at the far right of the data table.

Normality of the residuals. Analyze › Distribution › Y = Residual › OK › ▼Residual › Normal Quantile Plot, then Continuous Fit › Normal › ▼Fitted Normal › Goodness of Fit → Shapiro-Wilk Prob<W.

Residual plot. ▼Response y › Row Diagnostics › Plot Residual by Predicted. A random band around zero means the conditions hold; an arch or U means a line is the wrong form; a funnel means the variance is not constant; studentized residuals past ±3 are outliers.

Independence. Argue it from the design — a random sample of separate units is fine; be cautious when the data are consecutive years on the same place.

Is the predictor useful?

Test the slope. Fit Model › Run › Parameter Estimates, on the x row → t Ratio is the statistic, Prob>|t| the two-sided p-value, Std Error is SE(b₁). H₀: β₁ = 0, df = n − 2. State H₀, H₁, t, p and a conclusion in context.

One-sided? Halve Prob>|t|, but only if the sign of b₁ agrees with H₁; if it disagrees the p-value is above .5 and you fail to reject.

Testing a slope against a number other than 0. JMP only tests β₁ = 0. Either check whether the confidence interval contains that number, or compute t = (b₁ − c)/SE(b₁) with df = n − 2. "Do the data contradict a decrease of 2 per year?" → does the 99% CI contain −2?

Variation explained. Summary of Fit → RSquare. Say "___% of the variation in [y] is explained by the linear relationship with [x]."

The three intervals

CI for the slope. Right-click inside Parameter Estimates › Columns › Lower 95% + Upper 95% → read them on the x row, not the Intercept row. If it excludes 0, x is a useful predictor.

99% or 98% instead. ▼Response y › Set Alpha Level › 0.01 (or Other → 0.02), then re-read those columns. If your build locks them at 95%, compute b₁ ± t(α/2, n−2)·Std Error; get t from Formula › Probability › t Quantile(1−α/2, n−2).

CI for the mean response — "the average y for ALL cases with x = ___". Add a data row with that x and Y left blank, re-run Fit Model › Run › ▼Response y › Save Columns › Mean Confidence Interval → Lower / Upper 95% Mean on the row you added.

Prediction interval — "predict for ONE new case". Same setup, then Save Columns › Indiv Confidence Interval → Lower / Upper 95% Indiv. "Indiv" is always the wider one; both are centered on the same ŷ. Singular wording ("a truck", "a school", "a cafeteria") means Indiv.

Bands on the plot. ▼Linear Fit › Confid Curves Fit or Confid Curves Indiv — graph only, no numbers.

The blank Y matters. A row added for a prediction must have an empty Y cell, or it joins the fit and moves the line.

Unusual points. Click the point to highlight its row; Rows › Exclude/Unexclude then re-Run to see the effect. "How many more votes than predicted" = actual − predicted = that row's residual.

Multiple regression

Screen the predictors first. Analyze › Multivariate Methods › Multivariate › response + all predictors in Y, Columns › OK → Correlations plus a Scatterplot Matrix. The response row shows which predictor is most correlated with y; predictor-vs-predictor values above about .8 signal multicollinearity.

Fit it. Analyze › Fit Model › Y = response › highlight all predictors › Add › Run → Parameter Estimates gives ŷ = b₀ + b₁x₁ + ⋯ + bₖxₖ.

Interpret a coefficient: "For each additional one [xₖ-unit], the predicted [y] changes by bₖ [y-units], holding all other predictors constant." That last clause is where the points are.

Is the model useful? Analysis of Variance → F Ratio and Prob > F. H₀: all β = 0; H₁: at least one β ≠ 0. Rejecting means at least one predictor is useful, not all of them.

Is one predictor useful, adjusting for the rest? Parameter Estimates, that predictor's row → t Ratio, Prob>|t|, df = n − k − 1. The Effect Tests table gives the same p-value as an F. A predictor can look strong alone and still be non-significant here.

CI for a coefficient. Right-click Parameter Estimates › Columns › Lower 95% + Upper 95%; set a different level first with Set Alpha Level. Keep "holding the others constant" in the interpretation.

Conditions. Save Residuals and Studentized Residuals, use ▼Response y › Row Diagnostics › Plot Residual by Predicted, and run Distribution on the residuals for the histogram, NQ plot and Shapiro-Wilk. Multicollinearity numerically: right-click Parameter Estimates › Columns › VIF — above 5 is a warning, above 10 a problem.

Choosing a model

Compare with adjusted R². Summary of Fit → RSquare Adj, highest wins. Plain R² always rises when a predictor is added, so it cannot compare models of different sizes; R²adj = 1 − (1−R²)(n−1)/(n−k−1) penalizes extras.

All possible models. Fit Model › add all › Personality = Stepwise › Run › ▼ › All Possible Models → every subset with RSquare, RSquare Adj, Cp, AICc, BIC.

Backward selection. Fit Model › add all › Stepwise › Run, set Direction = Backward, Stopping Rule = P-value Threshold, Prob to Leave = 0.1, click Go → Current Estimates, a check under Entered means kept. Then Make Model → Run for the full report. By hand: remove the predictor with the largest p-value if it exceeds 0.1, refit, repeat — one at a time.

Predict from the chosen model. Plug the values into that model's equation, or add a row with those x's and a blank Y and save Predicted Values, or use ▼Response y › Factor Profiling › Profiler. Use the coefficients of the model you were told to use.

Polynomial (quadratic) regression

Quick route. Analyze › Fit Y by X › Y, X › OK › ▼Bivariate Fit › Fit Polynomial › 2, quadratic → a Polynomial Fit Degree=2 block with the uncentered equation printed above it.

Full route (use this for intervals). Analyze › Fit Model › Y › select x › Macros › Polynomial to Degree with Degree = 2 › Run → Parameter Estimates gains an x*x row.

Centering. JMP centers polynomial terms by default, printing (x − x̄)·(x − x̄) so the coefficients are not the raw b₀, b₁, b₂. Uncheck ▼Response y › Center Polynomials and Run again for the plain equation.

Is the quadratic useful? Test the squared term specifically: Parameter Estimates, the x*x row (or Effect Tests) → Prob>|t|. H₀: β₂ = 0 means a line is enough. The overall F can be significant just from the linear part, so don't use it here.

Change in y is no longer constant. change = b₁(x₂ − x₁) + b₂(x₂² − x₁²). From 0 to 1 that is b₁ + b₂; from 2 to 3 it is b₁ + 5b₂. The two differ — that is exactly the point of asking both.

Intervals from a quadratic. Add the row with x and a blank Y, fit with Polynomial to Degree 2, then Save Columns → Mean Confidence Interval for the average of all such cases, Indiv Confidence Interval for one specific new case.

Regression formulas

Sxx = Σ(x−x̄)²   Syy = Σ(y−ȳ)²   Sxy = Σ(x−x̄)(y−ȳ)  ·  b₁ = Sxy/Sxx   b₀ = ȳ − b₁x̄   r = Sxy/√(Sxx·Syy)

df: n − 1 for one mean · n − 2 for a simple-regression slope · n − k − 1 for a multiple-regression coefficient · k and n − k − 1 for the overall F.
