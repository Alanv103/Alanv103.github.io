Part 1

Inference for one mean

Everything here starts from Analyze › Distribution. Put the quantitative variable in Y, Columns and click OK — then every test, interval and plot hangs off the ▼ next to the variable's name (not the one next to "Distributions").

Setting up & describing

Is the variable categorical or quantitative?

Formula
QUANTITATIVE = a measured number you could average (weight in oz, diameter in inches, home price, perceived distance in feet, pounds of recycling) CATEGORICAL = a label putting each unit in a group (accepted / rejected, smoker / non-smoker, yes / no)
Note
This decides the whole rest of the problem: quantitative → a mean (Parts 1–2), categorical → a proportion (Part 3). Zip codes and jersey numbers are numbers but categorical.

Define the parameter in the context of the problem

Formula
μ = the TRUE MEAN [variable, with units] for ALL [units in the population]
Note
Three required pieces: the word mean, the variable with its units, and the population. Depth Perception: "μ = the true mean judged distance, in feet, for all airline pilots over 50 at this airline." Recycling: "μ = the true mean weekly weight of recyclable material, in pounds, per household in this city."

Open the data file

Path
File › Open › select the .jmp file › Open
Note
Check each column's modeling type in the data table: quantitative variables must show the blue continuous icon ▴. If one shows red bars (nominal), right-click the column header › Column Info › Modeling Type › Continuous.

Describe the shape / get x̄, s, and n

Path
Analyze › Distribution › Y, Columns = variable › OK
Answer
The histogram + box plot for shape. Numbers are in the Summary Statistics panel: Mean, Std Dev, N, and Std Err Mean (= s/√n).
Note
Describe shape (symmetric / skewed right / skewed left), center, spread, and any outliers shown as dots past the box whiskers.

Describe the sampling distribution of x̄

Path
No JMPHand-computed from μ, σ, n.
Formula
Mean of x̄ = μ SD of x̄ = σ / √n (this is the "standard error") Shape = Normal if the population is normal, or approx. Normal by the CLT if n ≥ 30
Note
Write all three parts — shape, mean, SD — and say why the shape is normal (stated normal population, or CLT with n ≥ 30).

"What's the chance the sample average is more than ___?"

Path
Cols › New Column › Column Properties › Formula › Functions › Probability › Normal Distribution(x, mean, SD)
Formula
z = (x̄ − μ) / (σ/√n) P(x̄ < a) = Normal Distribution(a, μ, σ/√n) P(x̄ > a) = 1 − Normal Distribution(a, μ, σ/√n)
Note
Faster on a test: compute z by hand and read the standard normal table. Use σ/√n, not σ — the question is about an average, not one observation.

The hypothesis test

State the null and alternative hypotheses

Path
No JMPRead the claim's wording.
Formula
H₀: μ = μ₀ (always "=", always the claimed number) "less than / decreased / lower" → H₁: μ < μ₀ "greater than / increased / higher" → H₁: μ > μ₀ "different from / changed" → H₁: μ ≠ μ₀
Note
μ is the population mean — define it in words ("μ = mean landings per trap since the restriction"). Never write x̄ in a hypothesis.

Run a one-sample t test (σ NOT given)

Path
Analyze › Distribution › Y, Columns = variable › OK › ▼ next to the variable name › Test Mean › type the hypothesized value › leave the "true standard deviation" box empty › OK
Answer
A Test Mean panel appears: t Test row gives the test statistic, then three p-values — Prob > |t|, Prob > t, Prob < t.
Note
Pick the p-value that matches H₁: ≠ → Prob > |t|  ·  > → Prob > t  ·  < → Prob < t. Ignore the Signed-Rank row (that's a nonparametric test).

Run a one-sample z test (σ IS given)

Path
Same as above, but in the Test Mean box also fill in "Enter True Standard Deviation to do z-test rather than t test" › OK
Answer
The panel now shows a z Test row with Prob > |z|, Prob > z, Prob < z.
Formula
z = (x̄ − μ₀) / (σ/√n) t = (x̄ − μ₀) / (s/√n), df = n − 1

Only summary statistics are given (no data table)

Path
No JMPDistribution needs raw data. Compute t by hand.
Formula
If they give s² (a VARIANCE), take the square root first. t = (x̄ − μ₀) / (s/√n) df = n − 1 p-value in JMP (Cols › New Column › Formula › Probability): two-tailed p = 2*(1 − t Distribution(|t|, df)) right-tail p = 1 − t Distribution(t, df) left-tail p = t Distribution(t, df)
Note
Worked (Home Prices): s² = 7,317,400,000 → s = 85,542. SE = 85,542/√69 = 10,298. t = (141,400 − 155,000)/10,298 = −1.32, df = 68, two-tailed p ≈ 0.19 > .05 → fail to reject; no evidence the mean price differs from $155,000.

"The sample statistic is 1.03 standard errors below the hypothesized value. Find the test statistic."

Path
No JMPRead it straight off the sentence.
Formula
t = −1.03 ("below" → negative; "above" → positive) The test statistic IS the number of standard errors the sample mean sits from μ₀. df = n − 1.
Note
For the p-value with n = 9 → df = 8, two-tailed: p = 2 × P(T₈ < −1.03). In JMP: 1 − t Distribution(1.03, 8) doubled, or use the t table.

Interpret the p-value

Path
WordingRead it off the Test Mean panel, then say this:
Formula
"If μ really were μ₀, there is a ___% chance of getting a sample mean at least this extreme purely by random sampling."
Note
It is not the probability H₀ is true. It is a probability computed assuming H₀ is true.

State the conclusion at level α

Formula
p ≤ α → REJECT H₀. "There IS sufficient evidence at the α level that [H₁ in words]." p > α → FAIL TO REJECT H₀. "There is NOT sufficient evidence at the α level that [H₁ in words]."
Note
Never say "accept H₀" and never say you "proved" anything. Always finish the sentence in the units of the problem.

"What assumption must be met for the p-value to be valid?"

Formula
1. Random sample / independent observations 2. Population is Normal — needed when n is small (n < 30). If n ≥ 30 the CLT covers it and only a wild outlier or extreme skew is a problem.
Note
For the small-n examples (9 athletes, 10 gallons of paint, 20 traps) the answer they want is the population distribution is approximately normal.

Check the conditions for using the t-test

Formula
INDEPENDENCE Stated random sample? → yes. Sample is less than 10% of the population? → yes. One measurement per unit (not repeated on the same person)? NORMALITY — any ONE of these is enough: The problem says the population is "approximately bell-shaped" / "follows a normal distribution", OR n ≥ 30, so the CLT applies, OR the histogram is roughly symmetric with no outliers AND Shapiro-Wilk gives Prob < W above α.
Note
Recycling (n = 50): the data are clearly right-skewed (mean 12.46 vs. median 8.6, max 48.5), but n = 50 ≥ 30, so the CLT makes the t-test valid anyway — say both halves of that. Peanuts / Apples / Depth Perception (n = 16, 12, 14): normality is met only because the problem states the population is bell-shaped.

Check the normality assumption

Path
In the Distribution report: ▼ next to the variable name › Normal Quantile Plot
then ▼ › Continuous Fit › Normal › ▼ next to "Fitted Normal" › Goodness of Fit
Answer
The Shapiro-Wilk W Test table: read Prob < W.
Note
Prob < W > α → normality is reasonable. Also say the histogram looks roughly symmetric and the points on the normal quantile plot follow the straight line inside the confidence bands.

Confidence interval for the mean

Confidence interval for μ

Path
Analyze › Distribution › OK → read Summary Statistics for the 95% one.
For any other level: ▼ next to the variable name › Confidence Interval › 0.90 / 0.95 / 0.99 / Other…
Answer
Summary Statistics rows Upper 95% Mean and Lower 95% Mean, or the separate Confidence Intervals table for other levels.
Formula
x̄ ± t(α/2, n−1) · s/√n (σ unknown) x̄ ± z(α/2) · σ/√n (σ known)
Note
Interpretation: "We are 95% confident the population mean [variable] is between ___ and ___ [units]."

Describe Type I and Type II errors in context

Formula
Type I = reject H₀ when H₀ is actually TRUE. P = α "We conclude [H₁ in words] when really [H₀ in words]." Type II = fail to reject H₀ when H₁ is actually TRUE. P = β "We conclude there's not enough evidence for [H₁] when really [H₁] is true."
Note
Both sentences must name the actual variable — e.g. "we conclude the additive raises mean coverage above 440 sq ft when it really doesn't."
Part 2

Power and Type II error

Almost all of this part is hand-computed — JMP has one power calculator and it only answers the last question type. Work it in a fixed order: (1) find the rejection region in x̄ units, (2) re-standardize that boundary using the true mean, (3) β is the probability of landing in the fail-to-reject region, (4) power = 1 − β.

"For what values of the sample mean will H₀ be rejected?"

Path
Step 1Hand-computed. This is the rejection region in x̄ units.
Formula
LEFT-tailed (H₁: μ < μ₀) reject if x̄ < μ₀ − zα · σ/√n RIGHT-tailed (H₁: μ > μ₀) reject if x̄ > μ₀ + zα · σ/√n TWO-tailed (H₁: μ ≠ μ₀) reject if x̄ < μ₀ − zα/₂·σ/√n OR x̄ > μ₀ + zα/₂·σ/√n z₀.₀₅ = 1.645 z₀.₀₂₅ = 1.96 z₀.₀₁ = 2.326 z₀.₀₀₅ = 2.576
Note
Worked example (Fertilizer): μ₀=50, σ=21, n=36, α=.05, left-tailed. σ/√n = 21/6 = 3.5. Reject if x̄ < 50 − 1.645(3.5) = 44.24.

"If the true mean is ___, what is P(Type II error)?"

Path
Step 2Re-standardize the critical x̄ using the true mean, not μ₀.
Formula
β = P(fail to reject H₀ | μ = μtrue) LEFT-tailed: β = P( x̄ > x̄crit ) z = (x̄crit − μtrue) / (σ/√n), β = 1 − Φ(z) RIGHT-tailed: β = P( x̄ < x̄crit ) z = (x̄crit − μtrue) / (σ/√n), β = Φ(z) TWO-tailed: β = P( x̄low < x̄ < x̄high ) β = Φ(zhigh) − Φ(zlow), each z using μtrue
Note
Worked (Fertilizer, μtrue = 43): z = (44.24 − 43)/3.5 = 0.354 → β = 1 − Φ(0.354) = 1 − .6387 = .3613.

"What is the power of the test?" / "What is the probability of detecting this difference?"

Path
Step 3Same two words, same computation.
Formula
Power = 1 − β = P(reject H₀ | μ = μtrue)
Note
These phrases all mean power: "probability of rejecting H₀ when the true mean is…", "probability of detecting this difference", "probability of correctly concluding…". These mean β: "probability of failing to reject", "probability of incorrectly failing to reject", "P(Type II error)". Fertilizer at μtrue=43: power = 1 − .3613 = .6387.

Get power from JMP directly

Path
DOE › Design Diagnostics › Sample Size and Power › One Sample Mean
fill in Alpha, Std Dev (σ), Difference to Detect (= |μtrue − μ₀|), Sample Size (n) › leave Power blank › Continue
Answer
JMP fills in the blank box — Power.
Note
CarefulThis calculator is two-sided by default. For the one-tailed fertilizer/paint questions it will disagree with your hand computation unless you check the one-sided option. On a one-tailed problem, trust the hand computation. Leaving Sample Size blank and filling Power instead answers "how big a sample do I need?"

"Sketch graphs illustrating α and the probabilities found above"

Formula
Draw TWO normal curves, one above the other, same horizontal axis: Top curve centered at μ₀ → shade the tail(s) past x̄crit = α Bottom curve centered at μtrue → shade the FAIL-to-reject side of x̄crit = β the other side = power Mark x̄crit with a vertical line through BOTH curves.
Note
The vertical line is at the same x̄ value on both curves — that's the whole point of the picture.

What makes power go up?

Formula
Power INCREASES when: n increases (smaller σ/√n) α increases (bigger rejection region — but more Type I risk) |μtrue − μ₀| increases (bigger effect is easier to detect) σ decreases (less noise) α and β trade off: lowering α raises β and lowers power, unless you also raise n.

"If an error was committed, what type might it be?"

Formula
You REJECTED H₀ → the only possible error is TYPE I You FAILED TO REJECT → the only possible error is TYPE II
Note
Then describe it in context. Lobsters (rejected H₀): "Type I — we concluded mean landings per trap dropped below 30.31 lbs when really they did not."
Part 3

Two proportions

First decide which kind you have — it changes everything. Independent: two separate groups of different people (statistical help vs. none; new drug vs. existing drug). Dependent / paired: the same people measured twice, or matched pairs (before/after the video; younger/older siblings). Independent → z test on p₁ − p₂. Dependent → drop the ties and run a binomial test on the discordant pairs.

Getting counts into JMP

Enter a summarized 2×2 table (you have counts, not raw rows)

Path
1. File › New › Data Table. Make three columns: Group (Nominal), Outcome (Nominal), Count (Continuous).
2. Type four rows — one per cell of the table.
3. Analyze › Fit Y by X › Y, Response = Outcome › X, Factor = Group › Freq = Count › OK
Answer
A Contingency Analysis report: mosaic plot, Contingency Table, and a Tests panel.
Note
CriticalForgetting to drop Count into the Freq box is the #1 mistake — JMP would then think you have 4 observations instead of 705. Statistician rows: (Help, Accepted, 222) (Help, Rejected, 293) (No Help, Accepted, 55) (No Help, Rejected, 135).

Independent proportions

Identify the explanatory and response variables

Formula
Explanatory = the GROUPING variable (categorical) Response = the OUTCOME measured (categorical)
Note
Statistician: explanatory = whether statistical assistance was provided (categorical); response = accepted or rejected (categorical). In Fit Y by X the explanatory goes in X, Factor and the response in Y, Response.

Point estimate of p₁ − p₂

Path
Read the Contingency Table. To see the proportions directly: ▼ next to "Contingency Table" › Row %
Formula
p̂₁ = x₁/n₁ p̂₂ = x₂/n₂ estimate = p̂₁ − p̂₂
Note
Worked (Statistician): p̂₁ = 222/(222+293) = 222/515 = .4311; p̂₂ = 55/(55+135) = 55/190 = .2895; difference = .1416. Divide by that group's own row total, never by the grand total.

Null and alternative hypotheses for two proportions

Formula
H₀: p₁ − p₂ = 0 (equivalently p₁ = p₂) "improves / enhances / higher" → H₁: p₁ − p₂ > 0 "lower / reduces" → H₁: p₁ − p₂ < 0 "different / any difference" → H₁: p₁ − p₂ ≠ 0
Note
"If acceptance is the same either way, what is true of p₁ − p₂?" → it equals 0. Statistician asks whether help improves publication → one-sided. Arthritis asks for different relief → two-sided.

Check the assumptions

Formula
1. INDEPENDENCE BETWEEN GROUPS Independently chosen random samples, or units were randomly ASSIGNED to the two treatments. (Arthritis: each person got only ONE drug — OK.) 2. INDEPENDENCE WITHIN GROUPS One response per person; no one influenced anyone else. 3. NORMALITY / LARGE SAMPLE — all FOUR must be ≥ 5: n₁p̂₁ n₁(1−p̂₁) n₂p̂₂ n₂(1−p̂₂) These are just the four CELL COUNTS of the table.
Note
Shortcut: condition 3 holds exactly when all four cells of the 2×2 table are at least 5. Statistician: 222, 293, 55, 135 — all well past 5. Still write out the four products if the question says "check".

Find the test statistic and p-value (independent)

Path
In the Contingency Analysis report: ▼ next to "Contingency Analysis of…" › Two Sample Test for Proportions
Answer
A panel giving p̂₁ − p̂₂, its standard error, and three p-values: Prob > |z|, Prob > z, Prob < z.
Formula
pooled p̂ = (x₁ + x₂) / (n₁ + n₂) z = (p̂₁ − p̂₂) / √[ p̂(1−p̂)(1/n₁ + 1/n₂) ]
Note
Match the p-value to H₁ exactly as in Part 1. Check which group JMP is calling "p₁" — it uses the first level alphabetically, which may be the reverse of your setup; if so the sign of z flips and you swap Prob>z with Prob<z. The Pearson ChiSquare in the Tests panel is the same two-sided test (χ² = z²), so its p-value matches Prob>|z|.

Interpret the test statistic and the p-value

Formula
TEST STATISTIC "The observed difference in sample proportions is z standard errors above/below 0, the value H₀ claims." P-VALUE "If the acceptance rate really were the same in both groups, there would be a ___% chance of seeing a difference in sample proportions at least this large just from random sampling."

Confidence interval for p₁ − p₂ (independent)

Path
The same Two Sample Test for Proportions panel reports the interval for the difference alongside the test.
Formula
(p̂₁ − p̂₂) ± zα/₂ · √[ p̂₁(1−p̂₁)/n₁ + p̂₂(1−p̂₂)/n₂ ]
Note
The interval is not pooled even though the test statistic is — the test assumes p₁ = p₂, the interval does not. An interval excluding 0 agrees with rejecting H₀ two-sided.

Dependent (paired) proportions

Label the paired 2×2 table before you do anything else

  • a = same both times, first category — a tie
  • b = changed one way (non-smoker → smoker) — discordant
  • c = changed the other way (smoker → non-smoker) — discordant
  • d = same both times, second category — a tie

Only b and c carry information. Smoking: a = 20, b = 5, c = 16, d = 9, n = 50.

Hypotheses for paired proportions

Formula
H₀: p_b = p_c (changes equally likely in both directions — the intervention did nothing) "was it effective?" → H₁: p_c > p_b (one-tailed) "is there a difference?" → H₁: p_b ≠ p_c (two-tailed)
Note
Equivalently H₀: p_b − p_c = 0. Smoking asks whether the video was effective → one-tailed, expecting more smoker→non-smoker changes. Puzzle asks whether there is a difference → two-tailed.

Count the ties, find n′ and the test statistic T

Formula
ties = a + d (everyone who did not change) n′ = b + c = n − ties (the discordant pairs) T = the count in the direction H₁ predicts
Note
Worked (Smoking): ties = 20 + 9 = 29; n′ = 50 − 29 = 21; H₁ predicts quitting, so T = smokers who became non-smokers = 16. Puzzle: ties = 27 + 18 = 45, n′ = 22, T = 13.

Find the p-value from the binomial distribution

Path
Cols › New Column › Column Properties › Formula › Functions › Discrete Probability › Binomial Distribution(p, n, k)
Formula
Under H₀, T ~ Binomial(n′, p = 0.5). right-tailed p = P(T ≥ t) = 1 − Binomial Distribution(0.5, n′, t−1) left-tailed p = P(T ≤ t) = Binomial Distribution(0.5, n′, t) two-tailed p = 2 × (the smaller one-tailed value) Binomial Distribution(p,n,k) = P(X ≤ k) cumulative Binomial Probability(p,n,k) = P(X = k) exactly k
Note
Worked (Smoking): p = P(T ≥ 16), T ~ Bin(21, .5) = 1 − Binomial Distribution(0.5, 21, 15) = .0133 < .05 → reject H₀; sufficient evidence the video was effective. Puzzle (n′ = 22, T = 13, two-tailed): p ≈ .52 > .05 → fail to reject; no evidence the two-year age gap changes the chance of solving it within a minute.

Get the paired test out of JMP instead of by hand

Path
Enter Before and After as two nominal columns plus a Count column › Analyze › Fit Y by X › Y = After, X = Before, Freq = Count › OK › ▼ › Agreement Statistic
Answer
Kappa plus a test of symmetry — on a 2×2 table that is McNemar's test, and its p-value is the two-sided one.
Note
CarefulThat is the large-sample chi-square version and it is two-sided only. The review's method is the exact binomial above — use it for the one-tailed smoking question and whenever n′ is small. Never run the ordinary two-proportion z test on paired data; it throws away the pairing.

Confidence interval for p_b − p_c (paired)

Path
No JMPHand-computed from a, b, c, d.
Formula
point estimate = (b − c) / n CI: (b − c)/n ± zα/₂ · √[ ((a+d)(b+c) + 4bc) / n³ ] where n = a + b + c + d.
Note
Worked (Smoking): (5−16)/50 = −.22; (29)(21) + 4(5)(16) = 929; 929/50³ = .007432; √ = .0862; 1.96(.0862) = .169 → (−.389, −.051) — entirely below 0, matching the rejected test. Puzzle: (9−13)/67 = −.060; (45)(22) + 4(9)(13) = 1458; √(1458/67³) = .0696 → (−.196, .077) — contains 0, matching the failure to reject.

Interpret a difference-of-proportions interval

Formula
"We are 95% confident that the difference in the proportion of [outcome] between [group 1] and [group 2] is between ___ and ___." Entirely above 0 → group 1's rate is genuinely higher. Entirely below 0 → group 1's rate is genuinely lower. Contains 0 → no significant difference.
Note
Smoking: "We are 95% confident the proportion who went non-smoker→smoker is between .051 and .389 lower than the proportion who went smoker→non-smoker" — far more people quit than started.
Part 4

Correlation & simple linear regression

Two doors into the same model. Fit Y by X is the fast one for plots and r. Fit Model is the one you need for confidence intervals, saved residuals and prediction intervals — when in doubt, use Analyze › Fit Model.

Which is the explanatory variable and which is the response?

Formula
Explanatory (x, predictor) = the one doing the predicting Response (y) = the one being predicted "Predict A using B" → y = A, x = B "Effect of B on A" → y = A, x = B
Note
Casinos: x = number of casino employees, y = crime rate. Graduation Rates: x = median SAT, y = 6-year graduation rate.

Create a scatterplot and comment on the relationship

Path
Analyze › Fit Y by X › Y, Response = response › X, Factor = explanatory › OK
Answer
The Bivariate Fit plot.
Note
Always comment on four things: direction (positive/negative), form (linear / curved), strength (weak / moderate / strong), outliers or unusual points. If the cloud bends, say a quadratic should be considered — that is the setup for Part 4.

Add the regression line to the scatterplot

Path
In the Bivariate Fit report: ▼ next to "Bivariate Fit of…" › Fit Line
Answer
The line is drawn on the plot, and a Linear Fit block appears underneath with the equation, Summary of Fit, Analysis of Variance and Parameter Estimates.

Find the correlation coefficient r

Path
Analyze › Multivariate Methods › Multivariate › put both variables in Y, Columns › OK
or, inside Fit Y by X: ▼ › Density Ellipse › 0.95 › open the "Correlation" panel
Answer
The Correlations table — read the off-diagonal value (the diagonal is always 1.0000).
Formula
r = Sxy / √(Sxx · Syy) Or from a fitted line: r = ±√RSquare take the SIGN of the slope b₁.
Note
Strength: |r| ≥ .8 strong · .5–.8 moderate · < .5 weak. Sign gives direction. r has no units and never exceeds 1 in absolute value.

What is the equation of the least squares regression line?

Path
Analyze › Fit Model › Y = response › select x in the column list › Add › Personality = Standard Least Squares › Run
Answer
Parameter Estimates table, Estimate column: the Intercept row is b₀, the row named after your x variable is b₁.
Formula
ŷ = b₀ + b₁x b₁ = Sxy / Sxx b₀ = ŷ̄ − b₁x̄
Note
Write it with the real variable names, not y and x: "Predicted Crime Rate = 1.026 + 0.0771(Employees)". Fit Y by X also prints the equation as a line of text right above Summary of Fit.

Use the equation to predict y when x = ___

Path
ArithmeticSubstitute into ŷ = b₀ + b₁x.
Or let JMP do it: add a new row with that x and Y left blank, then in Fit Model ▼ › Save Columns › Predicted Values
Note
Watch the units. If x is "employees in thousands", then 34,000 employees means x = 34, not 34000. Don't extrapolate far outside the range of x in the data.

Interpret the slope in context

Formula
"For each additional ONE [x-unit], the PREDICTED / AVERAGE [y variable] increases (or decreases) by |b₁| [y-units]."
Note
Two traps the review pushes on: say predicted or average — an individual case will not change by exactly b₁; and never claim x causes y from observational data.

Interpret the intercept

Formula
"When x = 0, the predicted [y] is b₀ [y-units]."
Note
Add the caveat whenever x = 0 is outside the data range or physically impossible (SAT score of 0, 0% with a diploma): the intercept is only a mathematical anchor for the line, not a meaningful prediction.

▼ next to the residual column name › Normal Quantile Plot

Residual plot — is there a pattern? Is the variance constant?

Path
Fit Model report: ▼ next to "Response y" › Row Diagnostics › Plot Residual by Predicted

Answer
The scatter of residuals against predicted values, centered on the zero line.

Is the independence assumption reasonable?

Formula
YES if the data came from a RANDOM SAMPLE of separate units (different counties, different schools, different trucks). Be cautious if the data are measured OVER TIME on the same unit (10 consecutive years of casino data) — consecutive years can be correlated.
Note
This one is argued from the problem's description, not from any JMP output.

Is the predictor useful?

Is x a useful predictor of y? (test the slope)

Path
Analyze › Fit Model › Y, Add x, Run → read Parameter Estimates
Answer
On the x variable's row: t Ratio is the test statistic, Prob>|t| is the two-sided p-value. Std Error on that row is SE(b₁).
Formula
H₀: β₁ = 0 H₁: β₁ ≠ 0 t = b₁ / SE(b₁) df = n − 2 One-sided H₁? p = (Prob>|t|)/2, but ONLY if the sign of b₁ agrees with H₁. If it doesn't, p > 0.5 — fail to reject.
Note
Write all five pieces: H₀, H₁, t = ___, p = ___, and the conclusion in context. The Analysis of Variance F test gives the identical p-value in simple regression (F = t²).

Path

Formula

ROUTE 2 — hand-computed t t = (b₁ − (−2)) / SE(b₁) = (b₁ + 2) / SE(b₁) df = n − 2, compare to t table or JMP: 2*(1 − t Distribution(|t|, n−2))

The three intervals — don't mix them up

Which interval does the question want?

  • CI for the slope β₁ — "confidence interval for the slope", "for how much y changes per unit of x". A range for the rate of change.
  • CI for the mean E(y) — "the average y for ALL cases with x = ___", "for all trucks with…", "every month…". Narrower.
  • Prediction interval for y — "predict the value for ONE new case", "a truck enters", "a school you're considering". Wider — it carries the randomness of a single observation on top of the uncertainty in the line.

Note
Interpretation: "We are 95% confident that for each additional one [x-unit], the average [y] changes by between ___ and ___ [y-units]." If the interval excludes 0, x is a useful predictor — that matches the p-value.

Is the model (as a whole) useful for predicting y?

Path

Answer
F Ratio is the test statistic, Prob > F is the p-value.
Formula

Note
This is the question when the wording is "is the model useful". If it asks about one specific predictor, that's the t test below instead. Reject → "at least one predictor is useful" — not "all of them are."

Comparing and selecting models

Which model is best? (adjusted R²)

Path
Every Fit Model report › Summary of Fit panel
Answer
RSquare Adj — pick the model with the highest value.
Formula
R²adj = 1 − (1 − R²)(n − 1)/(n − k − 1) R² ALWAYS rises when you add a predictor → useless for comparing models with different numbers of predictors. R²adj penalizes extra predictors → can go DOWN → use this.
Note
The full model always has the highest plain R², and that's exactly why the review asks about adjusted R² — the best model is usually a smaller one.

List all possible models and compare them

Path
Analyze › Fit Model › Y, Add all predictors › Personality = Stepwise › Run › ▼ next to "Stepwise Fit" › All Possible Models
Answer
A table of every subset with its RSquare, RSquare Adj, Cp, AICc, BIC.
Note
"Does any smaller model explain almost as much as the full model?" → scan for a 2- or 3-predictor model whose R² is within a point or two of the full model's. Best by any of: highest R²adj, lowest AICc, lowest BIC.

Perform backward model selection

Path
1. Analyze › Fit Model › Y = response › Add all predictors › Personality = Stepwise › Run
2. In the Stepwise Fit Control panel set Stopping Rule = P-value Threshold, Direction = Backward, Prob to Leave = 0.1
3. Click Go (or Step once per removal to watch it happen)
4. Click Make Model › Run to get the full report for the final model
Answer
The Current Estimates table — variables with a check in the Entered box are the ones that remain.
Formula
Backward selection, by hand: 1. Fit with ALL predictors. 2. Find the predictor with the LARGEST p-value. 3. If that p-value > 0.1 (the threshold), REMOVE it. 4. Refit without it. Repeat from step 2. 5. Stop when every remaining p-value ≤ 0.1.
Note
"Which variable should we remove first?" = the one with the largest p-value in the full model. Remove one at a time — p-values shift after each removal.

"If x goes from 2 to 3, how much does y change?" (quadratic)

Path

Formula

Traps that cost points

  • Prob>|t| is two-sided. For a one-tailed H₁, halve it — but only if the estimate's sign agrees with H₁. If the sign disagrees, the one-sided p-value is above 0.5 and you fail to reject.
  • Mean vs. Indiv. "Indiv" is the prediction interval for one new case and is always the wider one. Re-read the question for a singular noun ("a truck", "a school", "a cafeteria").
  • Units. If x is recorded in thousands, 34,000 employees is x = 34.
  • Blank Y. A row added to get a prediction must have its Y cell empty, or it changes the fitted line.
  • "Holding all others constant" must appear in every multiple-regression coefficient interpretation.
  • Centered polynomials. JMP centers x² by default; uncheck Center Polynomials before reading raw quadratic coefficients.
  • Never "accept H₀" — only "fail to reject". And never claim causation from observational data.
  • μ not x̄ in hypotheses, and define μ in the problem's own words.
  • Paired data is not two samples. If the same people appear in both columns, drop the ties and use the binomial test — the two-proportion z test is wrong there.
  • The Freq box. Analyzing a summarized table without putting the count column in Freq silently analyzes 4 observations.
  • Row percentages. p̂ for a group divides by that group's own row total, not the grand total.
  • Degrees of freedom. n−1 for one mean, n−2 for a simple-regression slope, n−k−1 for a multiple-regression coefficient.
