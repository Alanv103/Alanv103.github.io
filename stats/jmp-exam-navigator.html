Symbol key — what each letter means

Greek = the true value you can't seeμ "mew" — the true mean of the whole population · σ "sigma" — the true standard deviation, only when a problem gives it · α "alpha" — the significance level, the cutoff you compare p to (.05, .01) · β "beta" — the chance of missing a real difference · β₀, β₁ "beta-zero, beta-one" — the true intercept and slope · Σ big sigma — "add up over every data point" · χ² "chi-square" — the test JMP prints for a 2×2 table.

Latin = what your sample gives youx̄ "x-bar" — your sample average · s your sample standard deviation · n how many observations · p̂ "p-hat" — a sample proportion · b₀, b₁ the intercept and slope JMP prints · ŷ "y-hat" — a predicted y · e a residual: actual − predicted · SE standard error = σ/√n or s/√n · r correlation, −1 to +1 · R² share of y explained · df degrees of freedom · k how many predictors · t, z, F test statistics.A hypothesis is always about the Greek letter, never x̄. Careful: β alone is the Type II error chance, but β₀ and β₁ are regression slopes — same letter, two jobs.

Testing one mean

Is it a number or a group? If you could take an average of it, it's a number → use a mean. If it just sorts each person into a group (yes/no, accepted/rejected), it's a group → use a proportion.

Writing the hypotheses. H₀ always says μ equals the claimed number. "less / went down" → H₁: μ < · "more / went up" → > · "different / changed" → ≠.

Shape, average, spread, count. Analyze › Distribution › Y, Columns = variable › OK → the histogram shows the shape; Summary Statistics gives Mean, Std Dev, N and Std Err Mean.

t test — when they don't give you σ. Analyze › Distribution › Y = variable › OK › ▼variable › Test Mean › type the claimed number › leave the standard deviation box empty › OK → the Test Mean panel, t Test row.

z test — when they do give you σ. Same path, but also fill in "Enter True Standard Deviation to do z-test rather than t test" → the panel now shows a z Test row instead.

Which p-value to read. H₁ has ≠ → Prob>|t| · H₁ has > → Prob>t · H₁ has < → Prob<t. Ignore the Signed-Rank line.

Only summary numbers given. Distribution needs raw data, so use TestMean.jsl above, or t = (x̄ − μ₀) / (s/√n), df = n − 1. If they give s², square-root it first.

What has to be true, and intervals

Conditions for the t test. Independence: it's a random sample, it's less than 10% of the whole group, and each person is measured once. Bell shape: the problem says bell-shaped, or n ≥ 30 (big samples are fine either way), or the histogram looks even with no far-out points.

Checking the shape in JMP. ▼variable › Continuous Fit › Normal › ▼Fitted Normal › Goodness of Fit → Shapiro-Wilk Prob<W; if it's bigger than α, the bell shape is fine. Also ▼variable › Normal Quantile Plot — the dots should hug the straight line.

Confidence interval for the mean. Summary Statistics already lists Upper / Lower 95% Mean; other levels ▼variable › Confidence Interval › 0.99. Formula x̄ ± t(α/2, n−1)·s/√n.

If H₀ were true, and power

Describe the spread of sample averages when H₀ is true. Give all three. Shape: bell-shaped, because the population is bell-shaped or n ≥ 30. Center: μ₀. Spread: σ/√n.

Which sample averages make you reject? cutoff = μ₀ + (z)(SE), where SE = σ/√n and z carries the sign of the tail: −1.645 for a "less than" test, +1.645 for a "greater than" test at α = .05; for a two-sided test use μ₀ ± 1.96·SE. Reject when x̄ is past that cutoff.

β — the chance of missing a real difference. Take that same cutoff, but measure it from the true mean instead: z = (cutoff − μtrue)/(σ/√n). Then β is the chance x̄ lands in the "don't reject" zone.

Power = 1 − β. These all mean power: "chance of detecting this difference", "chance of rejecting H₀ when the true mean is ___", "chance of correctly concluding". These mean β: "chance of failing to reject", "chance of a Type II error".

Power from JMP. DOE › Design Diagnostics › Sample Size and Power › One Sample Mean, fill in Alpha, Std Dev, Difference to Detect and Sample Size, leave Power empty › Continue. Leaving Sample Size empty instead tells you how big a sample you'd need. It assumes a two-sided test, so on one-sided questions use the formula above.

Drawing it. Two bell curves on one line, one vertical line at the cutoff through both: top curve at μ₀, tail past the cutoff shaded = α; bottom curve at the true mean, "don't reject" side shaded = β, the rest power.

Two proportions — separate groups

A table of counts. File › New › Data Table with Group (Nominal), Outcome (Nominal), Count (Continuous), one row per box, like (Help, Accepted, 222). Then Analyze › Fit Y by X › Y = Outcome › X = Group › Freq = Count › OK → Contingency Table and Tests. Skip Freq and JMP thinks you have 4 people.

Best guess for the difference. ▼Contingency Table › Row %. Each p̂ is the count divided by that group's own row total, not the overall total. Example: 222/515 − 55/190 = .4311 − .2895 = .1416.

Hypotheses. H₀: p₁ − p₂ = 0 — if both groups have the same rate, the difference is zero. "improves" → > 0 · "reduces" → < 0 · "different" → ≠ 0.

What has to be true. Two separate random groups, or people randomly assigned to them; one answer per person; and all four counts in the table at least 5.

Test and interval. ▼Contingency Analysis › Two Sample Test for Proportions → the difference, its standard error, Prob>|z| / Prob>z / Prob<z, and the confidence interval. Pearson ChiSquare in the Tests panel is the same two-sided test.

Formulas. combined p̂ = (x₁+x₂)/(n₁+n₂), then z = (p̂₁−p̂₂) / √[p̂(1−p̂)(1/n₁+1/n₂)]. The interval does not combine them: (p̂₁−p̂₂) ± zα/₂√[p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂].

Two proportions — same people twice

Spotting it and reading the table. Same people measured twice, or matched pairs. a and d are the people who didn't change; b and c are the ones who switched, one each way. Smoking: a = 20, b = 5, c = 16, d = 9, n = 50. Don't use the test above — it ignores the pairing.

Only the switchers count. n′ = b + c. Everyone who stayed the same (a + d) gets dropped. T = how many switched in the direction H₁ expects. Smoking: 29 dropped, n′ = 21, T = 16. H₀ says switching is equally likely both ways.

The p-value. If H₀ is true, T acts like flipping a coin n′ times: T ~ Binomial(n′, 0.5). Cols › New Column › Formula › Discrete Probability › Binomial Distribution(.5, n′, k) gives the chance of k or fewer. Smoking: 1 − BinDist(.5, 21, 15) = .0133, under .05, so the video worked.

Or let JMP do it. Analyze › Fit Y by X › Y = After, X = Before, Freq = Count › OK › ▼ › Agreement Statistic → the test of symmetry is McNemar's test, but it only gives the two-sided answer.

Interval. (b−c)/n ± zα/₂√[((a+d)(b+c) + 4bc) / n³]. Smoking: (−.389, −.051), all below zero. Puzzle: (−.196, .077), which includes zero — no real difference.

Correlation and the best-fit line

Which variable goes where. "Predict A using B" → A is the response and goes in Y, Response; B does the predicting and goes in X, Factor.

Scatterplot. Analyze › Fit Y by X › Y, Response = response › X, Factor = factor › OK.

Add the line. ▼Bivariate Fit › Fit Line → equation printed right above Summary of Fit. For the curved bands around it: ▼Linear Fit › Confid Curves Fit or Confid Curves Indiv (picture only).

Correlation r. Analyze › Multivariate Methods › Multivariate › both variables in Y, Columns › OK → Correlations, the number where the two variables cross (the 1.0000s are each variable with itself). Or r = ±√RSquare, using the sign of the slope. r always lands between −1 and +1: the sign is the direction, the size is the strength — |r| ≥ .8 strong, .5–.8 medium, under .5 weak.

Equation of the best-fit line. Analyze › Fit Model › Y = response › select x › Add › Run → Parameter Estimates, Estimate column: the Intercept row is b₀, the x row is b₁.

Predict. Put the x value into ŷ = b₀ + b₁x. Watch the units — if x is in thousands, 34,000 means x = 34. Don't predict past the range of the data you have.

Checking it's OK to use the line

Save the leftovers. ▼Response y › Save Columns › Residuals, then again for Predicted Values and Studentized Residuals → new columns at the right of the data table. A residual is just actual − predicted.

Are the leftovers bell-shaped? Analyze › Distribution › Y = Residual › OK › ▼Residual › Normal Quantile Plot, then Continuous Fit › Normal › ▼Fitted Normal › Goodness of Fit → Shapiro-Wilk.

Leftovers plot. ▼Response y › Row Diagnostics › Plot Residual by Predicted. A shapeless band around zero is what you want · an arch or U means a line is the wrong shape · a funnel means the spread isn't even · a studentized value past ±3 is a far-out point.

Does x actually help predict y?

Test the slope. Fit Model › Run › Parameter Estimates, on the x row → t Ratio is the test number, Prob>|t| is the two-sided p-value, Std Error is the slope's wobble. H₀: the slope is 0, df = n − 2.

One-sided? Cut Prob>|t| in half, but only if the slope's sign matches what H₁ says. If it doesn't, the p-value is over .5 and you fail to reject.

Testing the slope against a number other than 0. JMP only tests 0. Either check whether the confidence interval contains that number, or use t = (b₁ − c)/Std Error, df = n − 2.

How much of y is explained. Summary of Fit → RSquare, times 100 for a percent.

The three intervals

Interval for the slope. Right-click inside Parameter Estimates › Columns › Lower 95% + Upper 95% → read them on the x row, not the Intercept row. If it doesn't include 0, x helps predict y.

99% or 98% instead. ▼Response y › Set Alpha Level › 0.01 (or Other → 0.02), then read those columns again. If yours is stuck at 95%: b₁ ± t(α/2, n−2)·Std Error, with t from t Quantile(1−α/2, n−2).

Interval for the average y — "for ALL cases with x = ___". Add a row with that x and leave Y empty (that keeps it out of the line), then Fit Model › Run › ▼Response y › Save Columns › Mean Confidence Interval → Lower / Upper 95% Mean on that row.

Interval for ONE new case. Same setup, then Save Columns › Indiv Confidence Interval → Lower / Upper 95% Indiv, always wider. A singular word — "a truck", "a school" — means use Indiv.

Far-out points. Click the point to light up its row, then Rows › Exclude/Unexclude and Run again. "How many more votes than predicted" = actual − predicted, which is that row's residual.

Several predictors at once

Look at them first. Analyze › Multivariate Methods › Multivariate › response + all predictors in Y, Columns › OK → Correlations and a grid of mini scatterplots. Two predictors with |r| above about .8 measure nearly the same thing, which causes trouble.

Fit it. Analyze › Fit Model › Y = response › highlight all the predictors › Add › Run → Parameter Estimates gives ŷ = b₀ + b₁x₁ + ⋯ + bₖxₖ.

Does the whole model help? Analysis of Variance → F Ratio and Prob > F. H₀ says every slope is 0. Rejecting means at least one predictor helps — not that they all do.

Does one predictor help, with the others in? Parameter Estimates, that predictor's row → t Ratio, Prob>|t|, df = n − k − 1. A predictor can look strong alone and still be useless here, because another one already covers it.

Interval for one coefficient. Right-click Parameter Estimates › Columns › Lower 95% + Upper 95%; change the level first with Set Alpha Level.

Checking conditions. Save Residuals, use ▼Response y › Row Diagnostics › Plot Residual by Predicted, and run Distribution on the residuals for the plot and Shapiro-Wilk. For overlap between predictors: right-click Parameter Estimates › Columns › VIF — over 5 a warning, over 10 a problem.

Picking the best model

Use adjusted R². Summary of Fit → RSquare Adj, highest one wins. Plain R² always goes up when you add a predictor, so it can't compare models with different numbers of predictors; R²adj = 1 − (1−R²)(n−1)/(n−k−1) takes a penalty for extras.

Every model at once. Fit Model › add all › Personality = Stepwise › Run › ▼ › All Possible Models → every combination with RSquare, RSquare Adj, Cp, AICc, BIC.

Dropping predictors one at a time. Fit Model › add all › Stepwise › Run, set Direction = Backward, Stopping Rule = P-value Threshold, Prob to Leave = 0.1, click Go → Current Estimates, a check under Entered means it stayed. Then Make Model → Run. The idea: throw out the biggest p-value above 0.1, refit, repeat.

Predicting from the model you picked. Put the values into that model's equation, or add a row with those x's and an empty Y and save Predicted Values, or use ▼Response y › Factor Profiling › Profiler.

Curved (quadratic) models

Quick way. Analyze › Fit Y by X › Y, X › OK › ▼Bivariate Fit › Fit Polynomial › 2, quadratic → a Polynomial Fit Degree=2 block with the plain equation printed above it.

Full way (use this one for intervals). Analyze › Fit Model › Y › select x › Macros › Polynomial to Degree with Degree = 2 › Run → Parameter Estimates gains an x*x row.

JMP shifts x first. By default it prints (x−x̄)·(x−x̄) instead of x², so the numbers aren't the plain b₀, b₁, b₂. Uncheck ▼Response y › Center Polynomials and Run again to get the plain equation.

Does the curve help? Test the squared term only: Parameter Estimates, the x*x row (or Effect Tests) → Prob>|t|. H₀ says the squared term is 0, meaning a straight line is enough. Don't use the overall F here — it can look good just from the straight-line part.

The change in y isn't the same every time. change = b₁(x₂ − x₁) + b₂(x₂² − x₁²). Going 0 to 1 gives b₁ + b₂; going 2 to 3 gives b₁ + 5b₂. They're different on purpose — that's the whole point of asking both.

Intervals from a curved model. Add the row with x and an empty Y, fit with Polynomial to Degree 2, then Save Columns → Mean Confidence Interval for the average of all such cases, Indiv Confidence Interval for one specific new case.

Numbers you may need to look up

df: n − 1 for one mean · n − 2 for a slope · n − k − 1 for one predictor out of k · k and n − k − 1 for the overall F.

z cutoffs: one-sided α = .10 → 1.282, .05 → 1.645, .025 → 1.960, .01 → 2.326 · two-sided 90% → 1.645, 95% → 1.960, 98% → 2.326, 99% → 2.576.

The formulas behind the line

Three building blocks. JMP never shows these three — they're only for working a small data set out yourself. Sxx = Σ(x−x̄)² spread of the x's, feeds the slope and its standard error · Syy = Σ(y−ȳ)² spread of the y's, feeds r and R² · Sxy = Σ(x−x̄)(y−ȳ) how much x and y move together, feeds the slope and r.

Everything else comes from those three. slope b₁ = Sxy/Sxx · intercept b₀ = ȳ − b₁x̄ (needs b₁ first) · the line ŷ = b₀ + b₁x · r = Sxy/√(Sxx·Syy) · R² = r² · one point's leftover e = y − ŷ. To check your work, your b₀ and b₁ should match Parameter Estimates.
