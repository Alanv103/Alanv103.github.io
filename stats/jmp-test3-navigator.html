odds ratio one odds ÷ another; 1 = no difference
exp(β) odds ratio per 1-unit rise in that x
median the middle value → use a nonparametric test
α "alpha" the bar you compare p to
H₀ the "nothing going on" tie — always has an =
H₁ what the question is trying to show

The decision rule — same for every test

Compare p to α. That is the whole decision. p < αREJECT H₀ → "there IS sufficient evidence that …" p > αFAIL TO REJECT H₀ → "there is NOT sufficient evidence that …" Never "accept H₀", never "prove". α=0.0100 vs p<0.0001: more zeros = smaller. JMP prints 0.0000 → you write p < 0.0001. saySince p p-value is less than α = .05, we reject H₀. There is sufficient evidence that H₁ in plain words. saySince p p-value is greater than α = .05, we fail to reject H₀. There is not sufficient evidence that H₁ in plain words. Chi-square is NEVER one-sided. No < or > version — you are asking "is something off?", not "is it bigger?" Always use Prob>ChiSq as printed.

Which test? — two questions sort all five

1. What is the RESPONSE you measured? a category→ chi-square, or logistic regression a number→ t / ANOVA, or a nonparametric test

2. Does the problem say "mean" or "median"? "mean"→ t test or ANOVA "median"→ nonparametric (Wilcoxon / Kruskal-Wallis)
what you seetest
1 category column + the problem gives you percentagesGoodness of Fit
2 category columns in a table, word "associated"Test of Independence
response is yes/no, predictors are numbersLogistic Regression
"median" + same subjects twiceWilcoxon Signed Rank
"median" + 3+ separate groupsKruskal-Wallis
Counts given in a table? You will need a Freq column in every one of these.
